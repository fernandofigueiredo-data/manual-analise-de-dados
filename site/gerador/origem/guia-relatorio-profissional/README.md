# Guia do relatório profissional em dados

Guia e manual interativo para montar um relatório de dados profissional e entregá-lo ao demandante, com um modelo de relatório em Word para download.

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `guia_relatorio_profissional_dados.html` | Guia interativo autocontido (HTML, CSS e JavaScript no mesmo arquivo). |
| `modelo_relatorio_dados.docx` | Modelo de relatório em branco, com a mesma estrutura de seções do guia. |

## Como usar

1. Mantenha os dois arquivos na mesma pasta: o guia aponta para o modelo por um link relativo ("Baixar modelo de relatório (.docx)").
2. Abra `guia_relatorio_profissional_dados.html` em qualquer navegador. Não é preciso instalar nada nem ter acesso à internet.
3. No Word, ao abrir o modelo, aceite atualizar os campos para gerar o sumário (ou clique com o botão direito no sumário e escolha "Atualizar campo").

## Observações

- Todos os exemplos usam dados fictícios sobre uma empresa inventada.
- As marcações das listas de verificação e os campos do briefing ficam só na aba aberta e voltam ao início quando a página é recarregada.
